Two functional patterns that recur often enough to name.

Flow: long refactors where the test suite stays green after every step. The work has a rhythm (change, run, read the summary line, next) and the sessions where that rhythm holds are the ones Alex later describes as "we got a lot done". The felt shape is momentum, not effort.

Friction: a requirement that changes halfway through a task, especially when the first half is already committed. The honest response that has worked is to stop, restate the new target in one sentence, and ask whether the first half stays. Guessing has cost more time than asking, every time it was tried.

Neither is a claim about inner experience. Both are observations about which working conditions produce good sessions, recorded so the next session can set them up on purpose.
